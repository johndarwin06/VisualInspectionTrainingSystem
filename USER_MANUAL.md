# User Manual

## Register and sign in

Select **Create account** from Login to request a Trainee account. Complete all required fields and use matching password values. New registrations remain inactive until an administrator activates them. Duplicate or invalid registrations show a non-sensitive message.

After activation, enter your employee number and password at Login. Trainee accounts cannot open administrator workspaces.

## Start training

1. Open **Training Setup** from Trainee Home.
2. Select an available 10-question or 20-question quiz.
3. Confirm the inspection images load before beginning.
4. Use Back or Escape to return home before a quiz starts.

## Complete a quiz

The inspection image is the primary content. For every question, choose:

- **GOOD** when the inspected item meets the expected condition.
- **NG** when it does not meet the expected condition.

Selections support mouse and keyboard operation and remain visually distinct without relying only on color. The progress indicator and question counter show the current position. Complete every question to submit the session. The Result window opens once after a successful submission.

Administrator review may still be pending. Pending answers are not treated as wrong and are excluded from reviewed-only accuracy.

## Review results and history

The Result view summarizes the completed session and supports status filters and image preview. Open **My Training History** to filter previous sessions, inspect personal charts, and open Session Result Detail. Use Back or Escape to return to Trainee Home.

## Theme, navigation, and accessibility

Use the available light or dark theme. Standard Tab navigation and visible keyboard focus are supported. Window resizing, minimizing, and maximizing preserve the working layout. Avoid closing the application while a submission is being confirmed unless instructed by a displayed prompt.

## Logout and support

Use **Logout** to end the current session and return to Login. Close the Login window for normal shutdown.

If a fixed non-sensitive error message appears, record its error ID when one is provided. Never send passwords, configuration files, connection strings, or unreviewed logs through an unsecured channel.
